# To-Do Demo

A single-page To-Do app built with HTML, CSS, and JavaScript.

## Run

Open `to-do-demo/to-do-list/index.html` in your browser.

## GitHub Pages

In this monorepo, deployment is managed by root workflows in:

- `.github/workflows/deploy-todo.yml`
- `.github/workflows/deploy-quote.yml`
- `.github/workflows/deploy-calculator.yml`
- `.github/workflows/deploy-task-checklist.yml`

Published route for this app: `/todo/`
