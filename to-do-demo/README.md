# To-Do Demo

A single-page To-Do app built with HTML, CSS, and JavaScript.

## Features

- Add tasks
- Mark tasks as complete
- Remove tasks
- Simple single-page layout

## Run Locally

Open this file in your browser:

- `to-do-demo/to-do-list/index.html`

## GitHub Pages Deployment

Primary workflow:

- `../.github/workflows/deploy-todo.yml`

Published route:

- `/todo/`
