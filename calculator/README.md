# Simple Calculator App

A responsive calculator web app built with HTML, CSS, and JavaScript.

## Features

- Basic operations: addition, subtraction, multiplication, division
- Decimal input support
- Keyboard support (`0-9`, `+`, `-`, `*`, `/`, `.`, `Enter`, `Backspace`, `Escape`)
- Light and dark mode toggle (sun/moon icon)
- Gradient-based UI and responsive layout for desktop and mobile
